如何在不重新编码的情况下剪切视频

默认剪切会复制现有流，因此速度很快，而且不会再次压缩视频。可选的 Smart Cut 会在受支持的视频中按照选定的帧边界剪切。

为什么实际剪切位置可能与指定时间不同

压缩视频以帧组的形式存储。关键帧可以独立解码，许多其他帧则依赖前面的帧。FFmpeg 从输入前方查找时间戳时，会从该时间之前最近的定位点开始处理。因此，使用流复制时，实际起点可能与输入的时间不同，尤其是在关键帧间隔较长时。

默认的流复制会保留已编码的视频，但无法保证从指定的开始时间精确剪切；实际起点可能落在前一个关键帧。可选的 Smart Cut 会在选定帧处剪切。对于受支持的帧间压缩视频，它会重新编码剪切边界，并在存在安全随机访问点时复制中间部分；某些选定片段可能需要整体重新编码，不安全的 GOP 布局会被拒绝。受支持的帧内压缩视频会全程复制。若含有音频，Smart Cut 会重新编码音频。

Smart Cut 的支持范围

Smart Cut 支持 MP4 或 MOV 中的 H.264 和 HEVC、MP4 中的 AV1、MP4 或 WebM 中的 VP9、MKV 或 WebM 中的 VP8，以及 MP4 或 MOV 中的 MPEG-4 和 MPEG-2。帧内编码的编解码器与容器组合如下：MJPEG 和 PNG 可用于 MP4、MOV、MKV 或 AVI；Ut Video 和 HuffYUV 可用于 MOV、MKV 或 AVI；FFV1 可用于 MKV、AVI 或 MOV；rawvideo 可用于 MKV；TIFF 可用于 MOV 或 MKV；HAP 和 DNxHD 可用于 MOV、MKV 或 AVI；ProRes 可用于 MOV。除 H.264 和 HEVC 外，输入和输出容器必须相同。

H.264 支持 8-bit 4:2:0 的 Constrained Baseline、Baseline、Main、High 或 High 10 配置文件；10-bit 仅支持 High 10 配置文件的 4:2:0、High 4:2:2 配置文件的 4:2:2 或 High 4:4:4 Predictive 配置文件的 4:4:4。HEVC 支持 Main 8-bit 4:2:0、Main 10 10-bit 4:2:0 或 RExt 10-bit 4:2:2/4:4:4。AV1 支持 Main 8-bit 或 10-bit 4:2:0；VP9 支持 Profile 0 8-bit 4:2:0、Profile 2 10-bit 4:2:0 或 Profile 3 10-bit 4:2:2/4:4:4。VP8 和 MPEG-4/MPEG-2 仅支持 8-bit 4:2:0。帧内编码格式支持 8-bit 或部分 10-bit 4:2:0/4:2:2 格式。可变帧率视频在帧时间戳有效且递增时受支持。Smart Cut 还要求视频为逐行扫描、方形像素、起始偏移为 0（短暂的 WebM Opus 预卷除外），且只能有一个视频流和至多一个音频流。不支持的组合会被拒绝。

快速剪切片段

  1. 打开 Mytory Video Tools 并选择“视频分割”。
  2. 载入视频并设置开始和结束时间。
  3. 要快速无损复制，请保持 Smart Cut 关闭后导出，起点可能会移到关键帧。若要在受支持的视频中按选定帧剪切，请开启 Smart Cut，以小数秒输入时间，然后导出。
